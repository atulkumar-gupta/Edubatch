# Setup Instructions

## Prerequisites
- Node.js 18+
- MongoDB Atlas account
- Razorpay account (test mode)

## Backend
1. cd server
2. npm install
3. cp .env.example .env (fill values)
4. npm run seed (optional - creates demo users)
5. npm run dev

## Frontend
1. cd client
2. npm install
3. cp .env.example .env
4. npm run dev
